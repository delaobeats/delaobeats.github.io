# My Life Journey Through Music

## Project Overview

**My Life Journey Through Music** is a two-page personal website created for my CMPA 3301 final project at Texas Tech University. The website tells the story of my development as a guitarist and musician, from learning guitar in high school to performing in bands, learning music production, and continuing to develop new musical and technical skills.

The homepage introduces my musical journey and how guitar developed into experiences with performing, songwriting, collaboration, and music production.

### About My Journey — `about.html`
The About page provides more detail about Formal Intent, learning music production and Ableton, and my more recent experiences with Honey & Virosa.

## Project Goals

- Create a functional two-page website.
- Use semantic HTML to organize website content.
- Use one shared external stylesheet for both pages.
- Create working navigation between the Home and About pages.
- Maintain a consistent visual design across the website.
- Make the website readable on desktop and smaller screens.
- Practice using GitHub for version control and project organization.
- Publish a functioning website using GitHub Pages.
- Apply project management concepts to the planning and development process.

## Project Management

The documentation includes a defined project scope, risk analysis using the TAME framework, a Work Breakdown Structure, and a final project retrospective. Advanced features such as JavaScript, databases, e-commerce, and music streaming were intentionally excluded to keep the project focused on the required two-page website.
