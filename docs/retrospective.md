# Project Retrospective

## Project Title
**My Life Journey Through Music**

## Overview
This project gave me the opportunity to combine something I am passionate about, music and guitar, with skills that were new to me at the beginning of this course. Building a website required me to use HTML, CSS, Visual Studio Code, GitHub, and GitHub Pages while also applying project management concepts.

Looking back, my biggest challenges were time management and learning unfamiliar technical skills. At the same time, overcoming those challenges became one of the most rewarding parts of the project.

## What Went Well?
One thing that went well was choosing a topic that I actually cared about. Building a website about my journey through music made the project more personal and gave me plenty of ideas for the content. I was able to connect the assignment to my experiences as a guitarist, band member, and someone who has learned music production.

I also became more comfortable using the technical tools introduced throughout the course. At the beginning, working with HTML, CSS, Visual Studio Code, GitHub, and repositories was unfamiliar to me. As I completed more assignments, I started to understand how those tools worked together.

Seeing a website that I created actually running through GitHub Pages was one of the biggest accomplishments for me. It showed me that I could learn a technical skill that initially seemed intimidating.

## What Went Wrong?
The biggest challenge throughout the project was time management. Balancing school assignments with work and personal responsibilities sometimes caused me to wait longer than I should have to begin certain tasks. When several requirements needed to be completed at the same time, it could become overwhelming.

Another challenge was learning a completely new skill while also trying to meet project deadlines. Sometimes something that looked simple took longer than expected because I first had to understand how to do it. Working with GitHub and Visual Studio Code was especially unfamiliar in the beginning.

Small problems could take additional time because I was not always sure whether an issue came from my HTML, CSS, file structure, GitHub repository, or another part of the project. As I gained more experience, troubleshooting became easier.

## What Would I Do Differently?
If I were starting the project again, I would begin working on smaller pieces earlier instead of allowing several tasks to build up near the deadline. Breaking the project into smaller goals would make the workload feel more manageable and provide more time for testing and revisions.

I would also spend more time practicing unfamiliar tools before beginning a major project with them. Even a small amount of additional practice with GitHub, Visual Studio Code, HTML, and CSS would have made some of the earlier assignments easier.

I also learned that I do not need to understand everything about a new skill before I start using it. Working through problems and making mistakes was part of how I learned. In the future, I would be more willing to experiment earlier instead of worrying about getting everything correct on the first attempt.

## Final Reflection
The biggest lesson I am taking away from this project is that learning a new technical skill takes time and practice. At the beginning of the course, creating and publishing my own website seemed unfamiliar and somewhat intimidating. By the end, I had a much better understanding of how HTML, CSS, Visual Studio Code, GitHub, and GitHub Pages work together.

The project also reinforced how important time management is when working on something unfamiliar. A task may take longer than expected when I am learning at the same time that I am building.

Overall, I am proud that I was able to take something I did not have much experience with and turn it into a functioning project. The finished website represents both my journey through music and my progress in learning web development and project management.
