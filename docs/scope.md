# Project Scope Statement

## Project Title
**My Life Journey Through Music**

## Project Purpose
The purpose of this project is to create a simple two-page personal website that tells the story of my journey as a musician and guitarist. Music has been an important part of my life since I began playing guitar in high school, and over time I have gained experience performing in bands, learning music production, recording music, and using tools such as Ableton.

This project combines one of my personal interests with the web development and project management skills I have developed throughout this course. The finished website will serve as both a personal story and an example of my ability to plan, build, document, and publish a basic website using HTML, CSS, GitHub, and GitHub Pages.

## Project Objectives
- Create a functional two-page website using HTML and CSS.
- Create an `index.html` page that introduces my journey through music.
- Create an `about.html` page with more information about my experiences as a guitarist, band member, and music producer.
- Create functioning navigation between the two pages.
- Use one shared external `style.css` file.
- Include personal content and imagery related to my experience as a musician.
- Maintain the required project documentation in a `docs/` folder.
- Publish the completed website using GitHub Pages.

## Major Deliverables
1. `index.html` — Main homepage introducing my musical journey.
2. `about.html` — Second page containing additional information about my experiences and growth as a musician.
3. `style.css` — One external stylesheet used by both pages.
4. `README.md` — Project overview with links to the live website and documentation.
5. `docs/scope.md` — Revised Project Scope Statement.
6. `docs/plan.md` — Project plan containing the risk analysis and Work Breakdown Structure.
7. `docs/retrospective.md` — Reflection on the project process.
8. A live website published through GitHub Pages.

## Desired Results and Success Criteria
The project will be considered successful when:
- Both HTML pages load correctly through GitHub Pages.
- Navigation works from the homepage to the About page and back.
- Both pages load the same external `style.css` file.
- The website uses the same color palette, typography, navigation style, and general spacing across both pages.
- Text and navigation remain readable on desktop and smaller screen sizes.
- Images resize appropriately without extending beyond the page layout.
- The website clearly communicates my personal journey through music.
- All required documentation is included in the `docs/` folder.

## Project Scope
The website will focus specifically on my personal development through music. Content includes my introduction to guitar in high school, experiences playing in bands, learning music theory, performing, recording, and becoming more involved with music production. It includes experiences from my first band, **Formal Intent**, through my more recent work with **Honey & Virosa**, along with learning the basics of Ableton and music production from my friend and former bandmate Mike.

## Project Exclusions
To prevent scope creep, the following are outside the project scope:
- JavaScript functionality.
- User accounts or login systems.
- Databases or server-side development.
- E-commerce or online shopping functionality.
- Music streaming or embedded streaming platforms.
- Complex animations or interactive effects.
- A large multi-page portfolio.
- Advanced web frameworks or libraries.

## Constraints
### Time
The project must be completed within the course deadline, requiring time management between planning, coding, testing, documentation, and submission.

### Quality
All links should work, content should be readable, and the site should display appropriately across desktop and smaller screen sizes.

### Budget
There is no expected financial cost. The project uses free development and hosting tools including Visual Studio Code, GitHub, and GitHub Pages.

## Stakeholders
- **Project Creator:** Responsible for planning, developing, testing, documenting, and publishing the website.
- **Instructor:** Evaluates whether the project meets technical, documentation, and project-management requirements.
- **Website Visitors:** View the finished website and experience the story and design.

## Peer Feedback and Revision
Peer feedback indicated that the project's purpose, objectives, exclusions, and overall scope were clear and realistic. Tate Neuman and Lori Martin both identified the visual design criteria as an area that could be more measurable.

Based on this feedback, the final scope defines specific visual success criteria. Both pages will use the same color palette, typography, navigation style, and spacing. Text and navigation must remain readable on desktop and smaller screens, and images must resize without extending beyond the page layout.
